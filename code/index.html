Code

Selected projects. Everything else is on GitHub.

Formalization

  • Cycle double cover conjecture in Lean
    A Lean 4 / mathlib formalization of OpenAI's proof of the cycle double cover conjecture for bridgeless multigraphs, built on a formalization of Jaeger's 8-flow theorem. Every theorem depends only on the standard axioms.
    GitHub DOI
  • No automorphism of order 7 of a Conway 99-graph
    A certified proof that no strongly regular graph with parameters (99, 14, 1, 2) has an automorphism of order 7. Lean 4 derives the statement from an explicit family of SAT cubes, and each cube's LRAT unsatisfiability certificate is checked by cake_lpr, a checker verified in HOL4.
    GitHub
  • Ten Challenges
    A Lean 4 formalization competition.
    Website GitHub

Computation

  • Hypergraph programs
    SageMath and Macaulay2 code for characteristic polynomials of hypergraphs: via resultants, with edge variables, Harary–Sachs coefficients, E‑characteristic polynomials, and Kocay's non-reconstructible hypergraphs.
    GitHub
  • Binary trees and tanglegrams
    SageMath programs for rooted binary trees and tanglegrams: minimal universal trees, counts of induced subtrees, and multidecks of tanglegrams.
    GitHub
